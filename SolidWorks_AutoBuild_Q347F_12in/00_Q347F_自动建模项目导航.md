# Q347F 12in Class150 自动建模项目导航

> 这份文件只做一件事：告诉你“想看什么，去哪里”。

## 1. 第一次看这个项目

按这个顺序：

1. `Q347F_参数驱动阀门3D自动建模系统_总体架构与Gate流程_V1.md`
   - 看整个系统为什么不是一条直线，而是 Gate + Resume + Validate + Publish。
2. `README.md`
   - 看当前已经实现到哪个 Stage、怎么运行、输出在哪。
3. 仓库根目录 `Q347F_12in_Class150_00_SKELETON_GlobalVariables_V1.txt`
   - 看当前唯一参数源。

---

看：

```text

```

---

## 7. 我要排查失败

先看：

```text
04_logs/run_YYYYMMDD_HHMMSS/build.log
04_logs/run_YYYYMMDD_HHMMSS/summary.json
```

再看本次 staging：

```text
03_backup/run_YYYYMMDD_HHMMSS/
```

排查顺序：

```text
先看失败 Stage
↓
再看失败 Object / Feature
↓
判断 DATA_ERROR / CAD_API_ERROR / DESIGN_ERROR
↓
修正
↓
resume
```

---

## 8. 我要继续开发下一阶段

不要把所有逻辑继续塞进一个 PowerShell 文件。

当前方向：

```text
01_scripts/lib/
```

继续按职责拆：

```text
Session
Equation
Geometry
Feature
Assembly
Validation
Stage
```

每一个新 Stage 都必须具备：

```text
输入
依赖
RUNNING
PASS/FAIL
Validator
staging
publish
resume
```

---

## 9. 整个项目最终要做到什么

```text
用户输入：
型号 + 口径 + 压力 + 参考总装图 + 标准/材料/工况

        ↓

设计数据
        ↓
Skeleton
        ↓
零件自动建模
        ↓
自动总装
        ↓
干涉/间隙/运动/错误校验
        ↓
工程图 + STEP + BOM + 报告
```

任何一步失败：

```text
不覆盖上次PASS
能定位错误
能从失败阶段继续
```

这就是本项目的核心原则。
