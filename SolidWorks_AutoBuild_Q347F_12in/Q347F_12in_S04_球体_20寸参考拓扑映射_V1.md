# Q347F 12in Class150 — S04 球体：20寸参考拓扑 → 12寸正式建模映射 V1

> **目标模型始终是：Q347F / NPS12 / DN300 / Class150。**  
> `20Q347F-300LB-03 球体.SLDPRT` 只用于读取公司成熟结构的特征顺序和功能拓扑，**禁止直接把20寸尺寸写进12寸制造模型。**

---

## 1. 本轮20寸深拆证据

来源：`reference_ball_deep_20260822_184331` + `reference_assembly_20260822_172715`。

### 1.1 20寸主体/流道

20寸 `草图2 → 旋转1`：

- 回转角：360°；
- 球面半径：约 R374，即名义球径约 Φ748；
- 两端宽度：560；
- 回转轮廓内边界半径：243.5，即流道 Φ487。

因此20寸成熟模型不是“先实心球再切流道”，而是回转轮廓本身同时包含球面和流道。

对12寸只迁移功能逻辑，不复制尺寸：

- `BALL_OD = Φ465`；
- `BORE_D = Φ303`；
- `BALL_W_X = 348`。

当前S04继续允许用“球体回转 + Φ303 Through All切除”实现，因为实体结果等价且API更稳定。

## 2. 上下支承孔：最重要的语义纠正

20寸 `草图3 → 切除-旋转1` 证明：

- 上球体支承孔功能尺寸为 Φ150；
- 下球体支承孔功能尺寸为 Φ105；
- 上下孔不是简单把“轴承长度”当成“从球面最高点开始的盲孔深度”。

12寸已经由轴承/前盖/底盖主链确定：

### 上球体主支承

```text
球体孔       Φ105
轴承         Φ105×Φ100×30
工作Z包络    +193.6 ～ +223.6
```

因此：

```text
上支承有效工作长度 = 30
球面最高点          = +232.5
孔底                = +193.6
从球面切入总深度    = 232.5 - 193.6 = 38.9
```

**30 mm 是轴承有效工作长度，不是球面切入总深度。**

### 下球体主支承

```text
球体孔       Φ70
轴承         Φ70×Φ65×50
工作Z包络    -227 ～ -177
```

因此：

```text
下支承有效工作长度 = 50
球面最低点          = -232.5
孔内端              = -177
从球面切入总深度    = 232.5 - 177 = 55.5
```

**50 mm 是轴承有效工作长度；约55.5 mm才是当前CAD从球面切入到内端的总深度。**

## 3. 上驱动槽：方向已由20寸源草图坐实

20寸 `草图4` 深拆坐标：

```text
X方向总宽 = 70
Y方向总长 = 112
圆角       = R12
深度参考   = 43
```

12寸既有粗模推演：

```text
44 × 70
R8
深27
```

结合20寸真实坐标方向，12寸应解释为：

```text
X方向 = 44
Y方向 = 70
R8
深27
```

此前S04曾写成 `X70 × Y44`，属于方向颠倒，V1起正式纠正。

驱动槽起始Z采用上支承孔底：

```text
Z_start = +193.6
Z_end   = 193.6 - 27 = +166.6
```

这与“上支承孔完成后再向球心方向加工驱动槽”的成熟拓扑一致。

## 4. 20寸两个M20孔：只保留证据，不复制到12寸

20寸 `草图15 → 切除-拉伸2 → M20 螺纹孔1` 深拆结果：

```text
两处沉台/预加工圆：Φ35
中心：X = ±105
中心距：210
沉台切深：10
Hole Wizard：M20
底孔：Φ17.5
钻孔深：40
螺纹深：30
```

这证明此前把 `105 / 35` 解释成“上支承孔Φ105×深35”是错误的。

对于12寸：

- 客户/12寸工艺规格尚未给出这两个工艺孔的正式规格；
- 不允许按20寸比例自动缩放螺纹；
- S04当前功能模型**暂不生成这两个工艺孔**；
- 待12寸工艺要求确认后，再作为独立可开关特征加入。

## 5. 20寸其他成熟特征证据

20寸源文件还确认：

- 倒角：2 mm / 20°；
- 最后圆角：R1；
- 流道口存在倒角/边缘处理；
- 球体最终为单实体。

12寸流道口倒角属于必须保留的功能特征，但**具体倒角尺寸要结合12寸DEVLON阀座和启闭刮擦空间后冻结**，当前不直接复制20寸 `2 mm / 20°`。

## 7. S04 PASS 门

12寸 `01_BALL.SLDPRT` 必须同时满足：

1. `BALL_CORE` 存在；
2. Φ303全通径存在；
3. Φ105上支承孔存在并到达 `Z≈+193.6`；
4. 上驱动槽实体方向为 `X44 × Y70`，R8，深27；
5. Φ70下支承孔存在并到达 `Z≈-177`；
6. 单一Solid Body；
7. X总宽≈348；
8. Y最大包络≈465；
9. 上下孔切除后的Z包络解析回读通过；
10. ForceRebuild PASS；
11. What's Wrong errors=0；
12. staging保存成功；
13. final发布成功。

只有通过这些Gate，S04才可进入S05阀座。
